## Sobre o projeto

A **GameGear** é uma landing page desenvolvida como projeto acadêmico durante o curso de **Tecnologia em Sistemas para Internet**, com foco no desenvolvimento front-end.

A proposta do projeto é apresentar uma plataforma voltada ao universo gamer, destacando periféricos, ofertas e informações sobre produtos por meio de uma interface visualmente atrativa e organizada.

O desenvolvimento foi direcionado à construção da interface, à organização dos elementos visuais e à experiência de navegação, aplicando conhecimentos adquiridos ao longo da formação.

**Acesse o projeto:** https://gamegear-rosy.vercel.app/

## Objetivos do projeto

- Aplicar conhecimentos de desenvolvimento front-end na construção de uma página web.
- Desenvolver uma interface visual consistente e alinhada ao segmento gamer.
- Organizar informações e produtos de maneira clara e intuitiva.
- Praticar conceitos de estruturação, estilização e experiência do usuário.
- Criar um projeto prático para fins acadêmicos e de portfólio.

## Tecnologias utilizadas

- **HTML5:** estruturação dos elementos e do conteúdo da página.
- **CSS3:** criação do layout, estilização dos componentes e identidade visual.
- **JavaScript:** implementação de interações, conforme utilizado no projeto.
- **Vercel:** hospedagem e publicação da landing page.

## Foco no desenvolvimento front-end

O projeto prioriza a apresentação visual e a experiência do usuário, explorando a organização dos elementos da interface, a hierarquia das informações, a composição do layout e a consistência visual.

A GameGear representa a aplicação prática dos conhecimentos de desenvolvimento web adquiridos no curso de Tecnologia em Sistemas para Internet, contribuindo para o aprimoramento das habilidades de criação de interfaces.
